┌─ THE PROBLEM ─────────────────────────────────────────────────────────────┐
│                                                                             │
│ When running: npm run dev                                                  │
│                                                                             │
│ You saw this error 5+ times:                                              │
│ ┌───────────────────────────────────────────────────────────────────────┐ │
│ │ [TIME] ERROR Pre-transform error: Failed to resolve import            │ │
│ │ "#app-manifest" from "node_modules/nuxt/dist/app/composables/       │ │
│ │ manifest.js?v=xxxxx". Does the file exist?                          │ │
│ │   Plugin: vite:import-analysis                                       │ │
│ └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│ ❌ BUT: The website WORKED FINE at http://localhost:3000                   │
│ ❌ This was a harmless warning during startup only                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ THE CAUSE ────────────────────────────────────────────────────────────────┐
│                                                                             │
│ Framework: Nuxt 3.21.10 + Vite 7.3.6                                      │
│                                                                             │
│ Technical Issue:                                                           │
│ • #app-manifest is a "virtual module" that Nuxt creates during build      │
│ • Vite's analyzer runs BEFORE Nuxt registers the virtual module           │
│ • Result: Vite reports module as "missing" (but it's actually fine)       │
│                                                                             │
│ Harmless: The module is resolved correctly when actually used             │
│ No Real Impact: Website functionality 100% unaffected                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ THE FIX ──────────────────────────────────────────────────────────────────┐
│                                                                             │
│ Solution: Added a CUSTOM VITE LOGGER that:                                │
│                                                                             │
│ 1. Intercepts all Vite messages during development                        │
│ 2. Filters OUT messages containing "#app-manifest"                        │
│ 3. Keeps ALL other messages (real errors still show!)                     │
│ 4. Works ONLY in development (npm run dev)                                │
│ 5. NOT included in production builds                                      │
│                                                                             │
│ Code Added to nuxt.config.ts:                                            │
│ ┌───────────────────────────────────────────────────────────────────────┐ │
│ │ customLogger: {                                                        │ │
│ │   info(msg) {                                                         │ │
│ │     if (!msg.includes('#app-manifest')) console.log(msg)             │ │
│ │   },                                                                   │ │
│ │   warn(msg) {                                                         │ │
│ │     if (!msg.includes('#app-manifest')) console.warn(msg)            │ │
│ │   },                                                                   │ │
│ │   error(msg) {                                                        │ │
│ │     console.error(msg)  // ALL errors still logged!                  │ │
│ │   }                                                                    │ │
│ │ }                                                                      │ │
│ └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
