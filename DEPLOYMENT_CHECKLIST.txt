ISSUES & TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

If build fails on Vercel:
  → Check Vercel dashboard logs
  → Run "npm run build" locally and reproduce
  → Compare with this documentation
  → Review error message carefully

If site shows 500 error:
  → Check Vercel function logs
  → Verify environment variables
  → Test with "npm run preview" locally
  → Inspect browser console (F12)

If performance is slow:
  → Clear browser cache
  → Check network tab (F12)
  → Test on different device
  → Check Vercel analytics

If certain page doesn't load:
  → Verify page file exists in pages/
  → Check page component for errors
  → Test locally with npm run dev
  → Review route configuration
