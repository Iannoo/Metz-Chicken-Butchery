# Required Images

Please add the following images to this directory:

1. `hero-chicken.jpg` - A high-quality image of free-range chickens in a natural environment (recommended size: 1920x1080px)
2. `whole-chicken.jpg` - Image of a whole chicken product (recommended size: 800x600px)
3. `chicken-breasts.jpg` - Image of chicken breasts (recommended size: 800x600px)
4. `chicken-wings.jpg` - Image of chicken wings (recommended size: 800x600px)
5. `logo.png` - Company logo (recommended size: 200x200px)

All images should be:
- High quality and professionally shot
- Optimized for web (compressed)
- In JPG format for photos, PNG for logo
- Properly licensed for commercial use

Note: You can use placeholder images during development, but please replace them with actual product images before going live.
